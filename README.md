# Mentor Forge

メンタリング（1on1）のスキルを、知識だけで終わらせず、ケースへの回答・他者との比較・現場実践の振り返りまで一続きで練習するWebアプリケーションです。

G's Academyの卒業制作として開発しています。

## 公開環境

- [Mentor Forgeを開く](https://limejackal58.sakura.ne.jp/mentor-forge/public)

本サービスは学習・検証用です。実際の相談や支援を受け付けるものではありません。テスト時は実在人物を特定できる情報を入力しないでください。

## 主な機能

- 利用前・利用後の対話振り返り診断
- ケース閲覧と自由回答
- 回答後の匿名回答比較
- 気になる回答の選択と差分振り返り
- 次に試す行動の記録
- 2週間後・4週間後の実践記録
- ソロ練習
- トリオ練習
- メンタリング基礎クイズ

## セキュリティ

- 秘密情報は環境変数で管理し、リポジトリへ登録しません
- 回答投稿前は他者回答を取得・表示しません
- 回答・振り返り・追跡記録は本人だけが操作できます
- 本番環境では設定ファイル、依存関係、ログへの直接アクセスを遮断しています
- 企画書は関係者だけに限定共有し、公開URLをリポジトリへ記載しません
- 公開IssueやREADMEには、個人情報・認証情報・サーバー内部情報を記載しません
