# Mentor Forge

メンタリング（1on1）のスキルを、知識だけで終わらせず、ケースへの回答・他者との比較・現場実践の振り返りまで一続きで練習するWebアプリケーションです。

G's Academyの卒業制作として開発しています。

## 公開環境

- [Mentor Forgeを開く](https://limejackal58.sakura.ne.jp/mentor-forge/public)

本サービスは学習・検証用です。実際の相談や支援を受け付けるものではありません。テスト時は実在人物を特定できる情報を入力しないでください。

## 卒業制作企画書

- [Canvaで企画書を見る](https://canva.link/c1r6ojp4vkowk4q)

企画書は2026年8月17日に事務局へ提出済みです。

## 主な機能

- 利用前・利用後の対話振り返り診断
- ケース閲覧と自由回答
- 回答後の匿名回答比較
- 気になる回答の選択と差分振り返り
- 次に試す行動の記録
- 2週間後・4週間後の実践記録
- ソロ練習
- トリオ練習
- メンタリング基礎クイズ

## 現在の状況

2026年9月6日時点で、ケースドリルの中核動線、本番デプロイ、DB更新、アクセス制御、本人パイロットを完了しています。次はスマートフォン実機確認と、5〜8名の外部ユーザーテストを実施します。

進捗と検証記録は[Issues](https://github.com/mai-san447/mentor-forge/issues)に記録しています。

- MySQL
- Blade / Livewire

- Tailwind CSS
- GitHub Actions

## セキュリティ

- 秘密情報は環境変数で管理し、リポジトリへ登録しません
- 回答投稿前は他者回答を取得・表示しません
- 回答・振り返り・追跡記録は本人だけが操作できます
- 本番環境では設定ファイル、依存関係、ログへの直接アクセスを遮断しています
- 公開IssueやREADMEには、個人情報・認証情報・サーバー内部情報を記載しません
