# Issue #4 作業報告書

作成日: 2026-09-05  
対象: Issue #4「回答選択・差分振り返り・次の行動を実装する」  
期限: 2026-09-13

## 1. 実装方針

Issue #3で実装した「自分で回答してから他者回答を見る」に続けて、次の学習動線を追加した。

1. 自分の最初の回答を確認する
2. 他者の実回答を最大6件、匿名A〜F・ランダム順で見る
3. 気になる回答を1件選ぶ
4. 選んだ理由と自分の回答との違いを書く
5. 次の面談で試す行動を決める
6. ケース画面とマイページで後から確認する

模範回答、点数、人気ランキング、AI生成回答は使用しない。

## 2. 完了条件との照合

| 完了条件 | 対応 |
| --- | --- |
| 気になる回答を1つ選択 | 他者回答のラジオ選択を実装 |
| 選択理由を入力 | 必須・最大2,000文字で保存 |
| 自分の回答との違いを入力 | 必須・最大2,000文字で保存 |
| 次に試す行動を登録 | 必須・最大1,000文字で保存 |
| 入力内容を後から確認 | ケース詳細に保存済み振り返りを表示 |
| マイページに学習履歴を表示 | ダッシュボードに最新5件と件数を表示 |
| 他ユーザーの個人情報を表示しない | 回答取得をID・本文だけに限定 |
| Feature Testを追加 | 8件を追加 |

## 3. 安全性とデータ整合性

- 自分のケース回答がなければ振り返りを保存できない。
- 自分自身の回答や別ケースの回答は選択できない。
- 1利用者・1ケースにつき振り返りは1件に制限する。
- 選択した回答本文は匿名のスナップショットとして保存し、元回答が削除されても学習履歴を維持する。
- 回答者の氏名、メール、経験年数は表示しない。

## 4. 検証

PRのGitHub ActionsでVite、Pint、PHPStan、Feature・Unit Testを実行する。
