## 1. 調査結果

2026-08-05時点の既存コードには、AIペルソナと会話する「ソロ練習」はあったが、Issue #3が求める次の体験は未実装だった。

1. ケースを読む
2. 自分の自由回答を1回だけ投稿する
3. 投稿前は他者回答を見られない
4. 投稿後に限り、他者回答を匿名で比較する

そのため、既存のソロ練習を変更せず、独立した「ケースドリル」として追加した。

## 4. セキュリティ・匿名性

- 未回答者の画面では、他者回答を取得するSQL自体を実行しない。
- 回答後の一覧取得項目は `id`、`content`、`created_at` に限定する。
- 回答一覧にユーザー名・メールアドレスを渡さない。
- `user_id + scenario_id` にユニーク制約を設け、競合を含む二重投稿をDBでも防止する。
- 回答の更新・削除ルートは設けないため、他人の回答を編集できない。
