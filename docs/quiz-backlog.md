# クイズ出題候補リスト（メンターに必要な知識・スキル）

最終更新: 2026-08-05

出題内容を決めるための候補リスト。実際の設問は
[`database/seeders/MentorForgeSeeder.php`](../database/seeders/MentorForgeSeeder.php) の
`questions()` に配列を足すだけで増やせる。`question` をキーにした `firstOrCreate` なので、
追記しても既存の設問は書き換わらない。

凡例: **●** 出題済み ／ **○** 未出題（今後の候補）

---

## A. 関係の土台

| | 項目 | 中身 |
| --- | --- | --- |
| ○ | 心理的安全性をつくる | 話しても不利にならないという前提を先に用意する |
| ○ | **守秘とその境界** | どこまで内密にするか、共有が必要な場合の扱い |
| ○ | 最初の合意 | 目的・頻度・扱う範囲をはじめに決めておく |
| ● | メンターの役割 | 上司・評価者との違い。決めるのは本人 |
| ○ | 自己開示の使い方 | 自分の話をどこまで、何のためにするか |

## B. 聴く

| | 項目 | 中身 |
| --- | --- | --- |
| ● | 遮らずに最後まで聴く | 解決策を先に出さない |
| ● | 沈黙を待つ | 沈黙は考えを整理している時間 |
| ● | 言い換え・要約で確認する | 受け取り方のずれをその場で直す |
| ○ | **非言語に注意を向ける** | 表情、声の調子、間 |
| ○ | 言葉と様子が食い違うとき | 「大丈夫」と言うが表情が硬い場面の扱い |

## C. 問う

| | 項目 | 中身 |
| --- | --- | --- |
| ● | 開かれた質問と閉じた質問 | 事実確認と、考えを広げる場面の使い分け |
| ● | 「なぜ」の言い換え | 「何が」「どのように」に置き換える |
| ○ | 具体化して掘り下げる | 抽象的な言葉を場面レベルまで下ろす |
| ○ | 未来志向の質問 | 原因追及でなく「どうしたいか」 |
| ○ | 誘導尋問を避ける | 答えを含んだ質問をしない |

## D. 受け止める

| | 項目 | 中身 |
| --- | --- | --- |
| ● | まず感情を受け止める | 整理より先に受け止める |
| ● | 共感と同情の違い | 外から見るか、隣に立つか |
| ○ | 評価・判断を保留する | 良し悪しを先に決めない |
| ○ | **アドバイスの誘惑に抗う** | 先回りして答えを渡さない |

## E. 伝える

| | 項目 | 中身 |
| --- | --- | --- |
| ● | フィードバックは行動に絞る | 人柄でなく、行動とその結果 |
| ● | 時間を置かずに伝える | 事実が新しいうちに、短く |
| ○ | 良かった点を具体的に言語化する | 「すごい」では再現できない |
| ○ | 受け手の準備を確認してから伝える | 伝えてよいか一言おく |
| ○ | Iメッセージで伝える | 「私にはこう見えた」 |

## F. 前に進める

**この分野はまだ1問も出題していない。**
ソロ練習には振り返りの入力欄があり、シナリオの目標も「本人の次の一歩を引き出す」となっている。
アプリがやっていることをクイズが扱えていない状態なので、優先して埋めたい。

| | 項目 | 中身 |
| --- | --- | --- |
| ○ | **目標は本人が決める** | メンターが決めた目標は続かない |
| ○ | **次の一歩を小さくする** | 実行できる大きさまで刻む |
| ○ | **振り返り（省察）を促す** | やりっぱなしにせず、意味づけを本人に言葉にしてもらう |
| ○ | 記録を残し次回につなぐ | 前回何を決めたかを持ち越す |

## G. 限界と安全

| | 項目 | 中身 |
| --- | --- | --- |
| ● | 専門家・窓口につなぐ判断 | メンターは専門家ではない |
| ○ | 抱え込まない | メンター自身のケア |
| ○ | 依存させない関係をつくる | 自分で歩けるようにするのが目的 |

## 12問への絞り込み方針（検討中）

全問必須回答のため、答えるのに疲れない **12問前後** を上限とする。

### 現在の構成

傾聴3 ／ 質問3 ／ 共感2 ／ フィードバック2 ／ 役割2 = 12問

### 検討中の案（6分野 × 2問）

| 分野 | 選ぶ2つ |
| --- | --- |
| 関係の土台 | メンターの役割 ／ **守秘** |
| 聴く | 遮らずに聴く ／ 沈黙を待つ |
| 問う | 「なぜ」の言い換え ／ 開かれた質問 |
| 受け止める | まず感情を受け止める ／ 共感と同情 |
| 伝える | 行動に絞る ／ タイミング |
| 進める・安全 | **省察を促す** ／ 専門窓口につなぐ |

入れ替えは2問。**守秘**と**省察を促す**を入れ、傾聴と質問から1問ずつ減らす。

> **未確定。** どれを外せないか、どれが不要かはユーザー判断待ち。
> 決まるまで現在の12問のままとする。

## 増やすときの手順

1. `MentorForgeSeeder::questions()` に配列を追記する
2. `php artisan db:seed --class=MentorForgeSeeder --force`（既存は書き換わらない）
3. `correct_index` が選択肢の範囲内にあることを必ず確認する。ここがずれると採点が静かに壊れる
