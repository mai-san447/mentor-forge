# 自分で行うパイロット通しテスト

対象日: 2026-09-06  
対象環境: さくら本番環境  
目的: 外部参加者を招く前に、MVPの中核動線を1人で最後まで確認する。

## 1. 本番反映後の準備

本番の `.env` に、自分がテストで使用するメールアドレスを設定する。

```dotenv
PILOT_TEST_MODE=true
PILOT_TESTER_EMAIL=実際にログインするメールアドレス
```

その後、アプリのディレクトリで実行する。

```sh
php artisan config:clear
php artisan migrate --force
php artisan db:seed --class=MentorForgeSeeder --force
php artisan config:cache
php artisan pilot:prepare
```

`pilot:prepare` は比較用の架空ユーザー3件と回答3件を冪等に作成する。ログイン可能なパスワードは発行しない。

## 2. 明日の操作順

スマートフォンで新規登録し、次の順に進める。途中で迷った箇所、期待と違った表示、エラー画面はスクリーンショットを残す。

1. 新規登録・ログイン
2. マイページの「利用前診断を始める」
3. 6項目に回答して保存
4. ケースドリルを開く
5. 自分の最初の返答を投稿
6. 匿名回答3件が表示されることを確認
7. 気になる回答を1つ選ぶ
8. 選択理由、自分との違い、次に試す行動を保存
9. マイページへ戻り、2週間後・4週間後が「記録できます」になっていることを確認
10. 2週間後の実践記録を保存
11. 4週間後の実践記録を保存
12. 利用後の再診断を行い、項目別の変化を確認
13. PCでもログインし、保存済み内容とレイアウトを確認

## 3. 判定基準

| 重要度 | 例 | 対応 |
| --- | --- | --- |
| 重大 | 登録不能、500、回答が保存されない、他人の個人情報が見える | 外部テストを止めて修正 |
| 重要 | 導線が分からず完了できない、スマホでボタンを押せない | 外部テスト前に修正 |
| 軽微 | 文言、余白、色、表記ゆれ | 記録し、後日まとめて修正 |

## 4. テスト終了後

比較用の架空アカウントと回答を削除する。

```sh
php artisan pilot:cleanup
```

本番 `.env` を通常状態へ戻し、キャッシュを更新する。

```dotenv
PILOT_TEST_MODE=false
PILOT_TESTER_EMAIL=
```

```sh
php artisan config:clear
php artisan config:cache
```

外部参加者のテストでは、パイロット用回答を使わず、参加者本人の実回答だけを匿名表示する。
